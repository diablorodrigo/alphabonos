# AlphaBonos · Terminal de Renta Fija & Macro Local
by AlphaQuant

Terminal analítica de Bonos Soberanos (Globales/Bonares), Curvas en Pesos (Lecaps, Boncer, Tamar, Duales, DL), Obligaciones Negociables (ONs), Provinciales, Tasas, Dólar, Futuros, Arbitrajes, Calendario Macro y Licitaciones del Tesoro.

## 🚀 Inicio Rápido
1. Ejecutar:
   ```bash
   python server.py
   ```
   (o en Windows doble clic en `Iniciar_AlphaBonos.bat`).
2. Abrir en el navegador: [http://localhost:8060](http://localhost:8060)
